The name

Wormifi is one word, pronounced worm-if-ee. It is not a typo of anything. It is not related to Wi-Fi, wireless networking, network security, malware, or any Nintendo fan server. Wormifi is an original browser game about pirates and treasure, and this page exists partly so that search engines and writers stop guessing otherwise.

What Wormifi is

Wormifi is a free pirate treasure arena game that runs in a web browser on desktop and mobile. You steer the head of a growing sea-serpent crew, collect recognisable pirate treasure to grow, and try to make rival captains cross your crew without steering your own head into theirs.

It plays solo against labeled AI in a ninety-second rush, an endless run, or a guided practice mode, and it has a live multiplayer preview where a shared room is simulated by one server authority rather than by each browser independently. There is no account, no download, no purchase, and no advertising. It installs to a phone home screen as a progressive web app, after which the solo modes run with no connection at all.

Play solo against labeled AI, or join a live multiplayer preview where one server authority decides every collision. Free, no account, no download.

Please avoid

Wormifi is a preview and the copy on this site is deliberately careful. Please do not describe it as massively multiplayer, as a proven large-scale network, or as having features it has not shipped. If a claim is not on this site, it is not one we are making.

Listing us

Wormifi is happy to be listed on game portals, directories, and roundups. Link to wormifi.com, use any description above verbatim, and use the key art as the thumbnail. No permission request is necessary.
