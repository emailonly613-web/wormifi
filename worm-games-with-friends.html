Playing a worm game with friends

The genre's best moment is cutting off someone who will yell about it from the next room. Most worm games make that strangely hard. Here's how friend play actually works.

Why friend play is rare in this genre

Classic worm arenas drop you on a random public server, and 'playing together' means both of you refreshing until the server list lines up — sometimes it never does. Games that solved it usually did so behind accounts, friend lists, and party systems: infrastructure that fights the genre's instant-play soul. The result is a genre built for rivalry that's oddly bad at rivalry between people who know each other.

How Wormifi friend rooms work

One shared code, zero accounts. Open the game's SETTINGS — the Captain's Quarters — and under PLAY TOGETHER press NEW ROOM to mint a code (or type any code you both agree on), or hit CHALLENGE A FRIEND to share your live room's link directly. Everyone who enters the same code lands in the same live arena — same board, same pace, same server referee. The room's first captain picks the board and speed for everyone; the population panel still counts humans honestly and labels every AI. That's the whole system: a code is the party.

Making a friend match actually good

Two suggestions from many hours of testing. First, pick the Harbor pace for a first session — the patient speed gives new players time to learn the collision rule before Tempest turns everything into reflexes. Second, agree on a rematch ritual: runs end fast in this genre, and the natural rhythm of a friend room is best-of-five with trash talk between deaths. The glossary will settle your arguments about what counts as a pinch.

The short version

Open Wormifi → FRIEND ROOM → NEW ROOM → send the link → both press PLAY LIVE. No download, no account, and the room is yours as long as you keep using the code.
