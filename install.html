Put Wormifi on your phone

Wormifi installs straight from the web onto Android and iPhone. Free, no account, no store listing, and the solo modes keep working with no signal.

Download for Android Or just play in the browser

Android — direct install

The Android package is 1.9 MB and installs like any app. Because it comes from this site rather than a store, your phone will ask you to confirm once.

  1. Tap Download for Android above. The file is wormifi.apk.
  2. Open the downloaded file. Android will say installing from this source is not allowed — tap Settings, turn on Allow from this source, then press back.
  3. Tap Install, then Open.

You only confirm that permission once, and only for the browser you downloaded with. Wormifi then behaves like any other app on the phone: its own icon, its own entry in the app switcher, and full screen with no address bar.

iPhone and iPad — add to home screen

Apple does not permit installing apps from outside its store, so on iPhone Wormifi installs as a web app instead. The result on screen is the same: an icon on your home screen that opens the game full screen with no browser interface.

  1. Open wormifi.com in Safari. This does not work in Chrome on iPhone — Apple only allows Safari to do it.
  2. Tap the Share button, the square with an arrow pointing up.
  3. Scroll down and tap Add to Home Screen, then tap Add.
  4. Tap the new Wormifi icon.

Safari will not prompt you on its own — Apple has never implemented the automatic install prompt that Android has. The four steps above are the whole process.

Desktop

In Chrome or Edge, an install icon appears at the right-hand end of the address bar once you have played for a moment. Clicking it gives Wormifi its own window with no browser interface.

Works without a connection

However you install it, the solo modes and these guide pages keep working with no network. Only the live multiplayer preview needs a connection, because only it has a server to answer to.

Why there is no app store listing

Wormifi is a web game, and a web game does not need a store in between. Installing from here means no store account, no 100 MB download, no waiting for a review queue, and updates that arrive the moment you open it. It costs nothing either way — there is nothing to buy in Wormifi.
