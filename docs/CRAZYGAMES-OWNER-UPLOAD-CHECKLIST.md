# CrazyGames owner upload checklist

## Codex supplies

- [ ] Validated ZIP with root `index.html`
- [ ] Build and ZIP hashes
- [ ] Three real gameplay screenshots
- [ ] Three-sentence description, short description, and controls
- [ ] Desktop and mobile local preview proof
- [ ] SDK loading/gameplay/ad lifecycle verification
- [ ] Explicit PASS/FAIL report

## Owner-only portal actions

- [ ] Create/sign into the CrazyGames Developer Portal account.
- [ ] Enter the true legal/business identity; do not use generated placeholder information.
- [ ] Review and accept the current publisher terms.
- [ ] Enter real tax and payout details directly into the portal.
- [ ] Upload the verified ZIP and listing media.
- [ ] Run the CrazyGames Preview/QA tool and preserve its results.
- [ ] Submit first for Basic Launch with rewarded UI disabled.
- [ ] Enable rewarded placements only after Full Launch approval.
- [ ] Request IAP/Xsolla access separately; it is invite-only.

## Do not claim yet

- CrazyGames acceptance or ad revenue before portal QA.
- Wormate-scale concurrency, global leaderboard, or lag-free performance.
- CrazyGames multiplayer/friend-invite compliance until the next phase integrates and proves `updateRoom`, invite parameters, join listeners, instant multiplayer, and room retention.
